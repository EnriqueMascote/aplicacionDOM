# Estructura del Proyecto

- **`/src/types`**  
  Definiciones de TypeScript

- **`/src/components`**  
  Componentes reutilizables

- **`/src/services`**  
  Lógica de negocio y conexiones a API

---

# Conceptos Demostrados

### a) Virtual DOM y JSX
- El componente `App.tsx` muestra cómo React utiliza JSX para describir la UI.  
- La actualización de tareas demuestra la reconciliación del Virtual DOM.

### b) Componentes Funcionales
- **`TaskForm`**: Manejo de formularios y entrada de usuario.  
- **`TaskItem`**: Componente reutilizable para cada tarea.

### c) Hooks y Estado
- **`useState`**: Para manejar estado local.  
- **`useEffect`**: Para efectos secundarios como cargar datos.

### d) Eventos
- **Mouse**: Botones de toggle, editar, eliminar.  
- **Teclado**: Manejo de Enter en el formulario.  
- **Formularios**: Prevención de envío por defecto.

### e) Async/Await y API
- Simulación de API con *delays*.  
- Manejo de estados de carga.  
- Tratamiento de errores.

### f) Animaciones y CSS
- Transiciones suaves en *hover*.  
- Animaciones de carga.  
- Efectos de *fade-in/out*.

---

# Características Destacadas
- Gestión completa de tareas (CRUD).  
- Estados de carga y error.  
- Interfaz responsiva y animada.  
- Validación de formularios.
